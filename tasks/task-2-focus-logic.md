# Задача 2: Логика автоматического и ручного фокуса

## Описание
Реализовать систему автоматического и ручного выбора задачи в фокусе с учетом времени начала (`startDate`) и окончания (`deadline`). 

## Приоритеты фокуса (от высшего к низшему):
1. **Срочная задача (ручной фокус):** Пользователь вручную выделил задачу (даже если её время еще не наступило). Она удерживает фокус до завершения или до ручного снятия фокуса.
2. **Просроченные задачи:** Время `deadline` прошло, а задача не завершена. При наличии нескольких просроченных задач, в фокус берется самая старая из них (с самым ранним `deadline`).
3. **Текущая задача:** Текущее системное время попадает в интервал между `startDate` и `deadline`. Если таких задач несколько, можно брать ту, что началась раньше (или имеет ближайший дедлайн).

## Требования
1. Обновить Zustand store (или хук), отвечающий за определение задачи в фокусе.
2. Написать чистую функцию для вычисления текущей задачи на основе массива всех задач и текущего времени.
3. (Опционально) Добавить периодическое обновление (таймер/интервал), чтобы фокус мог переключаться, когда наступает время следующей задачи, при открытом приложении.

## Критерии приемки
- Ручной фокус не сбрасывается автоматикой.
- При появлении просроченной задачи фокус переходит на нее (если нет ручного фокуса).
- При наступлении времени новой задачи фокус переходит на нее (если нет просроченных и ручного фокуса).
