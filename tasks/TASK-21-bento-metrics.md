# TASK-21: Правый Bento-блок продуктивности (Счетчики метрик)

- **ID:** `TASK-21`
- **Блок:** 5. Главная Страница (Дашборд / Обзор)
- **Статус:** Ожидает выполнения
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-06`

---

## 1. Цель задачи
Собрать верхнюю секцию правой колонки дашборда с двумя компактными Bento-карточками метрик продуктивности («ВЫПОЛНЕНО: X из Y» и «В ПЛАНЕ: N задач») с динамическим расчетом прогресса.

---

## 2. Техническое решение

### 2.1. Компонент `BentoMetricsRow.tsx` (`src/components/dashboard/BentoMetricsRow.tsx`)
1. **Карточка «ВЫПОЛНЕНО»:**
   - Заголовок с иконкой `check_circle` цвета Cyber Emerald (`text-secondary`).
   - Крупная цифра: `3 из 7 задач` (вычисляется из массива `items.filter(i => i.status === 'completed')`).
   - Сегментированный или сплошной прогресс-бар выполнения.
   - Бейдж динамики: `Продуктивность +34% к среде` (`text-secondary font-semibold`).
2. **Карточка «В ПЛАНЕ»:**
   - Заголовок с иконкой блокнота `assignment` цвета Electric Violet (`text-primary`).
   - Крупная цифра: `4 задачи` (незавершенные задачи дня).
   - Бейдж: `1 высокий фокус` (`bg-error/20 text-error rounded-full px-2 py-0.5`).
   - Оценка времени: `Оценка времени ~2.8 ч`.

---

## 3. Критерии приемки (Definition of Done)
1. Цифры и прогресс-бар автоматически пересчитываются при изменении статуса любой задачи.
2. Стили и расположение карточек в точности соответствуют строкам 210–260 макета `design/desktop_overview.html`.
