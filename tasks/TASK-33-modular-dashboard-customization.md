# TASK-33: Модульный Дашборд и Пользовательская Настройка Блоков

- **ID:** `TASK-33`
- **Блок:** 7. Глобальный UX, Хоткеи и Экспорт
- **Статус:** Выполнено
- **Приоритет:** Средний (P2)
- **Зависимости:** `TASK-06`, `TASK-21`, `TASK-22`, `TASK-23`

---

## 1. Цель
Предоставить пользователю возможность настраивать главный экран (Overview), скрывая ненужные блоки или включая опциональные модули (например, виджет недавних аудио), исключая визуальный перегруз.

---

## 2. Требования
1. **Набор модулей дашборда:**
   - `focusTask` — Виджет «Текущая активная задача» (включен по умолчанию).
   - `taskList` — Список задач на сегодня (включен по умолчанию).
   - `metrics` — Метрики дня («Выполнено» и «В плане», включены по умолчанию).
   - `dailySummary` — AI Дайджест дня (включен по умолчанию).
   - `recentAudio` — Виджет недавних аудиозаписей (СКРЫТ по умолчанию, включается по желанию).
2. **Интерфейс настройки:**
   - Кнопка «Настроить виджеты» в шапке дашборда или выпадающее меню.
   - Чекбоксы/тумблеры включения/отключения каждого модуля.
3. **Персистентность:**
   - Конфигурация видимости сохраняется в Zustand с сохранением в `localStorage`.

---

## 3. Архитектура и Реализация
- Стор: `src/store/dashboardConfigStore.ts`.
- Модальное окно или поповер: `src/components/dashboard/DashboardCustomizerModal.tsx`.

---

## 4. Критерии приёмки (DoD)
- [x] Виджет недавних аудио по умолчанию скрыт на главном экране.
- [x] Пользователь может через интерфейс включить или выключить любой блок.
- [x] Выбранное состояние модулей сохраняется после перезагрузки страницы.
