# TASK-49: REST API для заметок и аудиометаданных

- **ID:** `TASK-49`
- **Блок:** 9. Облачный backend и ИИ-обработка ввода
- **Статус:** Реализовано; автоматические проверки пройдены
- **Приоритет:** Критический (P0)
- **Зависимости:** `TASK-46`, `TASK-47`, `TASK-48`

## Цель

Предоставить веб- и мобильным клиентам единый авторизованный API для чтения и управления заметками.

## Контекст и связанные части проекта

Сейчас `useAppStore` обращается к `db` напрямую. Веб- и Expo-клиенты используют Node REST API; PostgreSQL доступна только серверу.

## Объём работ

- Реализовать `/api/v1/notes` для постраничного списка, чтения одной записи, создания, изменения и удаления.
- Поддержать фильтры по расписанию и статусу, сортировку и поля поиска, необходимые текущим страницам.
- Валидацию JSON/дат выполнять на сервере по `TASK-47`; использовать owner из проверенной сессии.
- Предусмотреть безопасную привязку аудиометаданных к заметке и API для чтения их состояния; загрузку/обработку файлов выполнять в отдельной задаче.
- Документировать запросы, ответы, ошибки и пагинацию в OpenAPI.

## Критерии приёмки

- Авторизованный клиент выполняет полный CRUD и получает только собственные записи.
- Невалидные поля и даты дают стабильные `4xx`-ответы; серверные ошибки не раскрывают секреты или stack trace.
- API контракт можно вызвать из браузера или Expo-клиента; клиент не получает credentials PostgreSQL.

## Проверки

- API integration tests на CRUD, пагинацию, фильтры, невалидный ввод и изоляцию владельцев.
- Проверка OpenAPI-примеров и серверной сборки.

## Зависимости

- `TASK-46` — авторизация и владелец.
- `TASK-47` — DTO и расписание.
- `TASK-48` — PostgreSQL-таблицы и изоляция репозитория.
