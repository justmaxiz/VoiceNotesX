# TASK-34: Интерактивная сортировка задач и списков (Interactive Task Sorting)

- **ID:** `TASK-34`
- **Блок:** 8. Улучшения интерфейса, логики и UX
- **Статус:** Выполнено
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-06`, `TASK-19`

---

## 1. Бизнес-цель и контекст
На дашборде в шапке списка задач присутствовал статический элемент `Сортировка: По приоритету` с иконкой стрелки, который не реагировал на клики и вводил пользователя в заблуждение. 
Цель — предоставить пользователю полноценный, интуитивный и отзывчивый механизм управления порядком задач: по приоритету, по дедлайну, по дате создания и по названию, с переключением направления и сохранением предпочтений.

---

## 2. Пользовательские сценарии (User Stories)
1. *Как пользователь*, я хочу кликнуть на «Сортировка: [Критерий]» и увидеть выпадающее всплывающее меню (Popover) со всеми доступными вариантами упорядочивания.
2. *Как пользователь*, я хочу в 1 клик перевернуть порядок (по возрастанию / убыванию) с помощью иконки направления (`↑` / `↓`).
3. *Как пользователь*, я хочу, чтобы выбранная сортировка сохранялась между перезагрузками страницы.
4. *Как пользователь*, я хочу, чтобы задачи без назначенного времени аккуратно группировались в конце списка под разделителем «Без точного времени», не мешая расписанию дня.

---

## 3. Функциональные и визуальные требования

1. **Выпадающее меню (Popover):**
   - Вызывается по клику на кнопку сортировки в шапке `DashboardTaskList`.
   - Варианты сортировки:
     - **По приоритету** (Срочные `high` -> `medium` -> `low`).
     - **По времени / дедлайну** (Ближайшие по времени первые).
     - **По дате создания** (Свежие добавленные первые).
     - **По названию** (Алфавитный порядок А–Я).
     - **Свой порядок** (Ручное перетаскивание Drag-and-Drop).
   - Индикация активного пункта галочкой (`check`).
   - Закрытие по клику вне меню или клавише `Escape`.

2. **Индикатор направления (`↑` / `↓`):**
   - Кнопка-переключатель направления рядом с названием критерия.
   - Плавная смена иконки и подсказки (например, «Сначала срочные» vs «Сначала несрочные»).

3. **Группировка задач без дедлайна:**
   - При сортировке «По времени» задачи с `time` / `dueDate` выводятся сверху в хронологическом порядке.
   - Задачи без указанного времени отделяются мягкой тонкой линией и заголовком «Без точного времени».

4. **Персистентность:**
   - Выбранный критерий и направление сохраняются в Zustand со связкой в `localStorage` (ключ `voicenotes_task_sort`).

## 4. Архитектура и Реализация

- **Компоненты:**
  - `src/components/dashboard/components/TaskSortMenu.tsx` — компонент выпадающего меню сортировки (Popover).
  - Модификация `src/components/dashboard/components/DashboardTaskList.tsx` — подключение стейта сортировки и функции `sortTasks(tasks, criteria, direction)`.
- **Стейт (`useAppStore` или локальный селектор):**
  - Поля: `sortBy: 'priority' | 'time' | 'created' | 'title' | 'manual'`, `sortDirection: 'asc' | 'desc'`.
  - Метод: `setSort(by, direction)`.
