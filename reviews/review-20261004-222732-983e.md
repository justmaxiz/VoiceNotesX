  - *Решение*: Монолит декомпозирован на 8 модульных компонентов в `src/components/dashboard/components/` (`DashboardHeader`, `FocusHeroCard`, `AudioWaveformPlayer`, `DashboardTaskList`, `DashboardTaskItem`, `QuickInputBar`, `ProductivityMetrics`, `RecentAudioWidget`, `DailySummaryCard`, `WorkspaceSyncCard`). Размер `DashboardOverview.tsx` уменьшен с 828 до 193 строк.

### High

  - *Решение*: Подключен вызов `setRecordingModalOpen(true)` на кнопках записи в Header, DashboardHeader, QuickInputBar и NotesPage. Кнопка «Новая задача» в TasksPage создает задачу в канбан-колонке.
- [FIXED] **[A11Y-01] [HIGH]** Отсутствие Focus Trap, возврата фокуса и избыточный слушатель Escape в `RecordingModal.tsx`.
  - *Решение*: Реализован полноценный Focus Trap по WAI-ARIA Modal Dialog, автофокус на кнопке при открытии, сохранение и возврат `previousActiveElement` при закрытии, слушатель `Escape` подключается только при открытом модальном окне.
- [FIXED] **[A11Y-02] [HIGH]** Отсутствие accessible label у поля ввода Gemini API Key в `SettingsPage.tsx`.
  - *Решение*: Добавлен `<label htmlFor="gemini-api-key">` со скрытым классом `sr-only` и атрибут `aria-label="Google AI Studio API Key"`.
- [FIXED] **[CSS-01] [HIGH]** Отсутствие CSS utility-классов отступов `mt-space-*`, `pl-space-*`, `pr-space-*` в `src/index.css`.
  - *Решение*: Добавлены полные наборы directional spacing utilities в `src/index.css` и подключены utility-классы `.glow-violet` и `.glow-emerald`.
- [FIXED] **[LAYOUT-01] [HIGH]** Отсутствие адаптивности для мобильных устройств (< 768px): жесткие `w-72`, `left-72`, `pl-72`.
