## 1. Цель задачи

Завершить клавиатурные и фокусные взаимодействия командной палитры и закрепить поведение поиска автоматическими регрессионными тестами.

## 2. Клавиатура и закрытие

- Использовать последовательный порядок Tab-фокуса для быстрых команд и результатов; Enter активирует сфокусированный элемент.
- Escape закрывает палитру и возвращает фокус элементу, который её открыл.
- Клик вне палитры закрывает её; выбор команды или результата также закрывает палитру.
- При повторном открытии фокус ставится в поле поиска, строка запроса очищается, список выбора сбрасывается.
- Доступные имена и роли поля поиска, быстрых команд и результатов должны быть понятны скринридеру.

## 3. Критерии приёмки

- [x] Все быстрые команды и результаты достижимы Tab и активируются Enter.
- [x] Escape закрывает палитру и возвращает фокус вызвавшему её элементу.
- [x] Клик вне палитры и выбор результата закрывают её.
- [x] Повторное открытие очищает запрос и устанавливает фокус в поле поиска.
- [x] Нет совпадений, пустой запрос и длинная прокручиваемая выдача доступны с клавиатуры.

## 4. Проверки

- Добавить тесты для Tab/Enter, Escape, клика вне, возврата фокуса, повторного открытия, пустого запроса и прокручиваемой длинной выдачи.
- Запустить unit/component-тесты поиска и командной палитры, затем полный `npm test` и `npm run build`.
- Не менять поведение глобальных хоткеев, навигации или модели данных за пределами требований этой задачи.
