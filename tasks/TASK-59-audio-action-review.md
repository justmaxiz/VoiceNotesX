# TASK-59: Просмотр и утверждение действий из аудио

- **ID:** `TASK-59`
- **Блок:** 9. Облачный backend и ИИ-обработка ввода
- **Статус:** Реализовано; автоматические проверки пройдены
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-47`, `TASK-49`, `TASK-53`, `TASK-56`, `TASK-58`

## Цель

Дать пользователю выбрать явные действия из анализа и сохранить только утверждённые записи.

## Контекст и связанные части проекта

Audio job возвращает транскрипт, сводку и candidates. Сейчас модель `StructuredResult` поддерживает один элемент и чек-лист; импортированное аудио может содержать несколько самостоятельных действий.

## Объём работ

- Показать найденные явные обязательства/действия отдельными редактируемыми строками с заголовком, описанием и извлечёнными датой/временем.
- Показывать кандидатов выбранными по умолчанию, разрешить снять выбор и исправить текст/расписание до сохранения.
- Сохранять кандидатов только после явного нажатия «Добавить выбранные»; повторный запрос после двойного клика не создаёт дубликаты.
- Сопутствующие шаги одной работы показывать чек-листом; не превращать идеи и пересказ в задачу автоматически.
- Сохранять транскрипт/сводку аудиозапроса как одну заметку/результат обработки; кандидаты создавать отдельными записями только после утверждения.
- Использовать schedule-driven contract: утверждённая запись без расписания остаётся заметкой; добавление расписания показывает её как запланированную задачу.

## Критерии приёмки

- Ни один кандидат не попадает в список заметок пользователя до явного подтверждения.
- Пользователь может утвердить часть кандидатов, снять остальные и исправить расписание.
- Повторное подтверждение того же job не создаёт копии.
- Отдельные действия и вложенные шаги отображаются раздельно; содержимое транскрипта сохраняется.

## Проверки

- Компонентные тесты выбора, редактирования, частичного подтверждения, пустого списка и повторного submit.
- API/store tests на idempotency и сохранение утверждённых записей владельцу job.

## Зависимости

- `TASK-47` — контракт единой заметки.
- `TASK-49` — backend create/update API.
- `TASK-53` — единые представления заметок и расписания.
- `TASK-56` — результат audio job.
- `TASK-58` — переход из уведомления в review.
