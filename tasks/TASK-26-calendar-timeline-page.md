# TASK-26: Страница «Календарь» с контрастной цветовой схемой

- **ID:** `TASK-26`
- **Блок:** 6. Дополнительные Страницы Приложения
- **Статус:** Выполнено
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-02`, `TASK-04`, `TASK-06`, `TASK-32`

---

## 1. Цель
Создать экран «Календарь» для наглядного планирования задач по дням недели и месяцам с исправленной высококонтрастной цветовой схемой (WCAG AAA), четко читаемыми плашками событий без темного фиолетового текста на темном фоне и аккуратными цветными маркерами категорий.

---

## 2. Требования

1. **Контрастная цветовая схема (Критическое визуальное исправление):**
   - **Строгий запрет:** никакого темного фиолетового текста на темном фоне (`text-primary` на темной подложке исключен).
   - **Плашки задач и событий:**
     - **Подложки:** глубокие полупрозрачные темные контейнеры поверхностей (`bg-surface-container` / `bg-surface-container-high` с тонкой рамкой `border border-outline-variant/30 hover:border-outline-variant/60`).
     - **Основной текст задачи:** чистый контрастный светлый текст (`text-on-surface` / `#e3e2e8`), обеспечивающий коэффициент контрастности к подложке более 12:1 (полное соответствие стандарту WCAG AAA).
     - **Второстепенный текст:** контрастный светло-серый тон (`text-on-surface-variant` / `#c4c7c5`) для таймкодов и метаданных.
   - **Аккуратные цветные маркеры категорий:**
     - Тонкие вертикальные полоски-индикаторы слева от текста плашки (`border-l-[3px] rounded-l-sm`):
       - **Emerald (`#4edea3` / `border-secondary`)**: релизы, деплой, разработка.
       - **Amber (`#ffb74d` / `border-amber-400`)**: ревью кода, встречи, согласования.
       - **Cyan (`#4fc3f7` / `border-cyan-400`)**: аналитика, метрики, отчеты.
       - **Violet (`#d0bcff` / `border-primary`)**: стратегия, архитектура, личные дела.

2. **Режимы отображения:**
   - Переключение между видами: «Месяц», «Неделя», «День (Timeline)».
   - **Сетка месяца:**
     - Календарная сетка 7x5/6 с номерами дней и днями недели.
     - Подсветка текущего дня (`ring-1 ring-primary/50 bg-surface-container-high/40`).
     - Отображение задач компактными плашками с контрастным текстом и левым цветным маркером категории.
   - **Почасовая шкала (Timeline дня):**
     - Интервалы с 08:00 до 22:00.
     - Карточки задач, спозиционированные по времени выполнения.
     - Клик по свободному временному интервалу открывает быстрое создание задачи на это время.

3. **Интерактивность:**
   - Клик по плашке события открывает детальную правую шторку (`TASK-32`).
   - Навигация: кнопки «Назад», «Вперед», «Сегодня».

---

## 3. Архитектура и Реализация

- **Компоненты:**
  - `src/components/calendar/CalendarPage.tsx` — контейнер экрана календаря.
  - `src/components/calendar/MonthGrid.tsx` — сетка месяца.
  - `src/components/calendar/DayTimeline.tsx` — почасовая временная шкала.
  - `src/components/calendar/CalendarTaskCard.tsx` — компонент плашки задачи с контрастным светлым текстом и левым цветным маркером.
- **Токены дизайн-системы:** строгое применение токенов Obsidian Lumina (`text-on-surface`, `bg-surface-container`, `border-outline-variant`).
- **Связка с данными:** выборка задач по полю `dueDate` из `useTaskStore`.

## 4. Критерии приёмки (DoD)

- [x] На всех плашках задач в календаре используется контрастный светлый текст (`text-on-surface`).
- [x] Полностью устранен нечитаемый темный фиолетовый текст на темном фоне.
- [x] Категории задач четко визуализируются аккуратными цветными маркерами слева (Emerald, Amber, Cyan, Violet).
- [x] Сетка месяца и почасовая шкала дня корректно отображают задачи с дедлайнами.
- [x] Клик по свободному слоту на шкале времени позволяет запланировать задачу на это время.
- [x] Клик по задаче открывает правую детальную шторку.
