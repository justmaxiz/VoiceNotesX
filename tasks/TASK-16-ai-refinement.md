# TASK-16: Цикл итеративной доработки промпта (Refinement Loop)

- **ID:** `TASK-16`
- **Блок:** 4. ИИ-модуль (Google AI Studio Gemini Flash)
- **Статус:** Выполнено
- **Приоритет:** Средний (P2)
- **Зависимости:** `TASK-15`

---

## 1. Цель задачи
Реализовать механизм быстрой корректировки результата ИИ-обработки без необходимости хранить тяжелую историю диалогов: пользователь вводит замечание, и предыдущий результат обновляется.

---

## 2. Техническое решение

### 2.1. Метод `refineStructuredNote`
Принимает:
- `currentData: StructuredResult` (текущий сгенерированный драфт).
- `userFeedback: string` (комментарий пользователя, например: *«Поменяй дедлайн на пятницу и добавь пункт в чеклист»*).

### 2.2. Промпт для модели
```text
У тебя есть существующий JSON объект:
${JSON.stringify(currentData)}

Пользователь хочет внести изменения:
"${userFeedback}"

Обнови JSON объект с сохранением структуры схемы.
```

---

## 3. Критерии приемки (Definition of Done)
1. Пользователь может нажать «Дополнить / Изменить» в модалке предпросмотра созданной заметки.
2. Новое указание успешно корректирует карточку (изменяет дедлайн, заголовок или состав чеклиста).
