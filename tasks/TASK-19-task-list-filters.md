# TASK-19: Интерактивный список задач дня и фильтрация

- **ID:** `TASK-19`
- **Блок:** 5. Главная Страница (Дашборд / Обзор)
- **Статус:** Ожидает выполнения
- **Приоритет:** Критический (P0)
- **Зависимости:** `TASK-06`

---

## 1. Цель задачи
Реализовать фильтры («Все 4», «Срочные 1», «Голосовые 3», «Сводки 1») и интерактивный список задач дня с кастомными чекбоксами, тегами категорий, дедлайнами и зачеркиванием выполненных.

---

## 2. Техническое решение

### 2.1. Компонент `TaskFilterTabs.tsx` (`src/components/dashboard/TaskFilterTabs.tsx`)
- Вкладки:
  - `Все 4` (активна по умолчанию, подсветка фиолетовым `bg-primary-container`).
  - `Срочные 1` (фильтр по `priority === 'high'`).
  - `Голосовые 3` (фильтр по наличию аудиозаписи / транскрипта).
  - `Сводки 1` (фильтр по типу `note`).
- Селектор сортировки: «По приоритету», «По дедлайну», «По алфавиту».

### 2.2. Компонент `TaskItemRow.tsx` (`src/components/dashboard/TaskItemRow.tsx`)
- Чекбокс:
  - Незавершенная задача: квадратная рамка `w-5 h-5 rounded-md border-outline-variant hover:border-primary`.
  - Завершенная задача: заливка Cyber Emerald (`bg-secondary`), белая галочка `check`, зачеркнутый текст заголовка, плашка `Выполнено в 14:15`.
- Мета-информация:
  - Тег категории (`#Аналитика`, `#Разработка`, `#Дизайн`, `#Финансы`) в виде скругленного бейджа.
  - Дополнительные бейджи (например, `1:15 Встреча с инвесторами`, `PR #142`, `3 заметки`).
  - Время дедлайна с иконкой часов (`schedule`).

---

## 3. Критерии приемки (Definition of Done)
1. Переключение табов мгновенно фильтрует список задач.
2. Клик по чекбоксу переключает статус задачи с плавной анимацией и звуковым/визуальным фидбеком.
3. Выполненные задачи корректно зачеркиваются и отображают время закрытия.
