# TASK-14: Сервис Google AI Studio (Gemini 2.0/2.5 Flash API Client)

- **ID:** `TASK-14`
- **Блок:** 4. ИИ-модуль (Google AI Studio Gemini Flash)
- **Статус:** Выполнено
- **Приоритет:** Критический (P0)
- **Зависимости:** `TASK-06`

---

## 1. Цель
Разработать клиент для взаимодействия с Google AI Studio (Gemini 2.0/2.5 Flash REST API) с конфигурацией API-ключа через переменные окружения (.env) без ручного ввода пользователем в UI, а также реализовать предустановленные режимы обработки: «Быстрый» и «Глубокий анализ».

---

## 2. Требования

### 2.1. Конфигурация API-ключа (Без ручного ввода в UI)
- **Исключить ввод API-ключа пользователем в интерфейсе (UI)**:
  - Никаких модальных окон, блокирующих баннеров или полей ввода ключа (BYOK) в настройках для конечного пользователя.
  - Ключ API задается исключительно в серверном файле `.env` или конфигурации сборки приложения (`import.meta.env.VITE_GEMINI_API_KEY` / переменные среды сервера).
- При отсутствии заданного ключа в окружении клиент прозрачно переключается в локальный Mock-режим: детерминированная качественная генерация задач и саммари без прерывания пользовательского опыта и без ошибок.

### 2.2. Предустановленные режимы генерации ИИ
1. **Режим «Быстрый» (Fast Mode) — по умолчанию:**
   - Оптимизирован под минимальную задержку (минимальный TTFT / latency).
   - Быстрое структурирование текста: выделение лаконичного заголовка, 3–5 ключевых тезисов и основных задач.
   - Минимальный расход токенов (`temperature: 0.2`, `maxOutputTokens: 1024`).
2. **Режим «Глубокий анализ» (Deep Analysis Mode) — для Pro-подписки:**
   - Расширенный контекстный анализ текста и связей.
   - Глубокая декомпозиция задач на подзадачи с оценкой дедлайнов, категоризацией, выявлением неявных договоренностей и рекомендациями.
   - Обогащенное форматирование Markdown и контекстные теги (`temperature: 0.4`, `maxOutputTokens: 4096`).
   - Доступен для пользователей с активной Pro-подпиской (`isProUser = true`).

---

## 3. Архитектура и техническое решение

### 3.1. Клиент API (`src/lib/gemini.ts`)
- Эндпоинт:
  `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=${API_KEY}`
- Источник ключа:
  ```typescript
  const API_KEY = import.meta.env.VITE_GEMINI_API_KEY || '';
  ```
- Определение режимов:
  ```typescript
  export type AIMode = 'fast' | 'deep';

  export interface ProcessNoteOptions {
    transcript: string;
    mode?: AIMode; // default: 'fast'
    isProUser?: boolean;
  }
  ```
- Конфигурация запроса в зависимости от режима:
  - `fast`: `generationConfig: { temperature: 0.2, maxOutputTokens: 1024 }`, сжатый системный промпт для мгновенного разбора.
  - `deep`: `generationConfig: { temperature: 0.4, maxOutputTokens: 4096 }`, расширенный системный промпт с декомпозицией шагов и категоризацией.

### 3.2. Локальный Mock-фоллбэк
- Если `!API_KEY` или при ошибках сети/квоты (429 Rate Limit):
  - Мгновенная генерация структурированного ответа локальным парсером на базе эвристик.
  - Пользователь видит результат без задержки и предупреждений о необходимости ключа.

- [ ] В интерфейсе пользователя (UI) полностью отсутствует форма или поле для ручного ввода API-ключа.
- [ ] API-ключ подхватывается исключительно из серверного `.env` / конфига окружения.
- [ ] Реализованы и протестированы два режима генерации: «Быстрый» (по умолчанию) и «Глубокий анализ» (для Pro).
- [ ] При отсутствии ключа в окружении приложение бесперебойно выдает реалистичный результат через локальный mock-движок.
