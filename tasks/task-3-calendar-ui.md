# Задача 3: Визуализация в календаре (UI)

## Описание
Задачи в компоненте календаря должны визуально растягиваться на весь свой временной интервал (от `startDate` до `deadline`), чтобы пользователь наглядно видел, сколько времени отведено на выполнение задания.

## Требования
1. **Календарная сетка:** Адаптировать отображение элементов задач в компоненте календаря.
2. **Вычисление размеров:** Высота (для вертикального дня) или ширина (для горизонтальных таймлайнов) блока задачи должна быть пропорциональна разнице между `deadline` и `startDate`.
3. **Позиционирование:** Блок задачи должен начинаться строго на отметке времени `startDate`.
4. **Визуализация фокуса/состояний:** Отображение просроченных задач и задач "в фокусе" (например, специальной рамкой, цветом или тенью) согласно дизайн-системе.

## Критерии приемки
- Двухчасовая задача (например, с 14:00 до 16:00) визуально занимает 2 часа в сетке расписания, а не отображается как точка в 16:00.
- Сохраняется корректное отображение других элементов календаря.
- Нет конфликтов позиционирования (overlapping) или они корректно обрабатываются визуально (например, задачи сдвигаются в сторону при наложении по времени).
