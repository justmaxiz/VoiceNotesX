# TASK-20: Командная строка быстрого ввода (Quick Input Bar)

- **ID:** `TASK-20`
- **Блок:** 5. Главная Страница (Дашборд / Обзор)
- **Статус:** Ожидает выполнения
- **Приоритет:** Критический (P0)
- **Зависимости:** `TASK-06`, `TASK-11`, `TASK-15`

---

## 1. Цель задачи
Реализовать плавающую строку быстрого ввода внизу списка задач, позволяющую создавать мысли и задачи текстом (по `Enter`), голосом (по кнопке микрофона) или отправлять на расширенный анализ в ИИ.

---

## 2. Техническое решение

### 2.1. Компонент `QuickInputBar.tsx` (`src/components/dashboard/QuickInputBar.tsx`)
- Внешний вид:
  - Полупрозрачная капсула со стекломорфизмом (`rounded-2xl bg-surface-container border border-outline-variant/30`).
  - Левая иконка: `auto_awesome` (ИИ-магия).
  - Поле ввода: плейсхолдер *«Быстрая мысль или задача... | Enter — сохранить»*.
  - Кнопка микрофона: переключение голосового распознавания с анимацией пульсации.
  - Кнопка «Добавить» / «ИИ Анализ» (`bg-primary text-on-primary rounded-xl`).
- Логика горячих клавиш:
  - Обычное нажатие `Enter`: мгновенное сохранение локальной задачи без обращения к API.
  - Нажатие `⌘Enter` / `Ctrl+Enter`: отправка текста в Gemini Flash для автоструктурирования.

---

## 3. Критерии приемки (Definition of Done)
1. Ввод текста и нажатие `Enter` немедленно добавляет новую задачу в список.
2. Клик по микрофону запускает живую диктовку прямо в поле ввода.
3. При отправке в ИИ отображается индикатор загрузки, после чего создается структурированная карточка.
