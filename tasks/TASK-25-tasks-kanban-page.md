# TASK-25: Страница «Задачи» с Канбан-доской и меню создания

- **ID:** `TASK-25`
- **Блок:** 6. Дополнительные Страницы Приложения
- **Статус:** Выполнено
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-04`, `TASK-06`, `TASK-20`, `TASK-32`

---

## 1. Цель
Разработать экран управления задачами с интерактивной Канбан-доской, поддержкой перемещения задач между колонками и выпадающим меню (попапом) при клике на добавление задачи («+»), позволяющим создать новую задачу через нижний Quick Capture виджет либо добавить задачу из существующих нераспределенных заметок/задач.

---

## 2. Требования

1. **Структура Канбан-доски:**
   - Четыре колонки жизненного цикла задач:
     1. **К выполнению (`todo`)**: входящие и запланированные задачи.
     2. **В фокусе (`focus`)**: приоритетные задачи текущего спринта/дня.
     3. **В процессе (`in_progress`)**: задачи в активной работе.
     4. **Выполнено (`completed`)**: закрытые задачи.
   - Заголовок каждой колонки: название, счетчик задач и кнопка добавления («+»).
   - Пустые состояния (плейсхолдеры): если в колонке нет задач, отображается аккуратная пунктирная карточка *«Перетащите задачи сюда»* или *«Нет задач»*.

2. **Выпадающее меню добавления задачи (попап по клику на «+»):**
   - При клике на кнопку «+» в шапке колонки открывается выпадающее контекстное меню (попап) с двумя действиями:
     1. **«Создать новую»**:
        - Программно выдвигает и активирует нижний плавающий Quick Capture Widget (`TASK-20`).
        - Фокусирует поле ввода, устанавливает `entityType: 'task'` и передает контекст текущей колонки (например, создание задачи сразу в статус `todo` или `in_progress`).
     2. **«Добавить из существующих»**:
        - Открывает модальное окно со списком нераспределенных заметок и задач (бэклог/заметки без привязанных задач).
        - Модалка содержит строку быстрого поиска и список доступных элементов.
        - При выборе нераспределенной заметки создается новая задача в целевой колонке со связкой на заметку и аудиозапись.
        - При выборе нераспределенной задачи из бэклога она переносится в статус целевой колонки.

3. **Интерактивность карточек задач:**
   - Быстрое перемещение задач между колонками (drag-and-drop или стрелки смены статуса).
   - Приоритеты задач (`low`, `medium`, `high`) с цветовой индикацией.
   - Дедлайны и цветные маркеры категорий.
   - Интерактивный прогресс подзадач (чек-лист `2/4`).
   - Клик по карточке открывает правую детальную шторку (`TASK-32`).

---

## 3. Архитектура и Реализация

- **Компоненты:**
  - `src/components/tasks/TasksKanbanPage.tsx` — корневой контейнер страницы задач.
  - `src/components/tasks/KanbanColumn.tsx` — колонка со списком карточек и кнопкой добавления («+»).
  - `src/components/tasks/KanbanCard.tsx` — карточка задачи.
  - `src/components/tasks/AddTaskMenu.tsx` — выпадающее меню добавления задачи (попап).
  - `src/components/tasks/ImportFromExistingModal.tsx` — модальное окно выбора нераспределенных заметок/задач.
- **Интеграция со сторами:**
  - `useQuickCaptureStore`: вызов `openQuickCapture({ targetColumn, entityType: 'task' })`.
  - `useTaskStore` и `useNotesStore`: операции связывания и перемещения задач в IndexedDB (Dexie.js).
  - `useDrawerStore`: вызов `openDrawer({ id: task.id, type: 'task' })` при клике на карточку.
