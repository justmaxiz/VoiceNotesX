# TASK-03: Анатомический каркас приложения и глобальная оболочка (App Layout Shell)

- **ID:** `TASK-03`
- **Блок:** 1. Фундамент и Дизайн-система
- **Статус:** Выполнено
- **Приоритет:** Критический (P0)
- **Зависимости:** `TASK-01`, `TASK-02`

---

## 1. Цель
Собрать гибкий анатомический каркас приложения (App Shell): сворачиваемый левый сайдбар, верхний хедер, нижний глобальный виджет быстрого захвата (Quick Capture) и адаптивный основной рабочий контейнер (Main Canvas).

---

## 2. Требования

### 2.1. Структура навигации в сайдбаре
- Раздел навигации называется строго **«Заметки»** (вместо устаревшего «Заметки и аудио»), так как голос является способом ввода, а не обособленной сущностью.
- Нормализованный идентификатор маршрута: `notes` (с поддержкой обратной совместимости для `#notes-and-audio`).
- Список вкладок:
  - Главная (Дашборд) — `overview`
  - Заметки [42] — `notes`
  - Задачи [12] — `tasks`
  - Календарь — `calendar`
  - AI Сводки — `ai-summaries`
  - Настройки — `settings`

### 2.2. Механизм сворачивания боковой панели (Sidebar Collapse)
- Поддержка сворачивания и разворачивания сайдбара:
  - По сочетанию клавиш **`Ctrl+B`** (или `⌘B` на macOS).
  - По нажатию специальной кнопки-тоггла в интерфейсе сайдбара и хедера.
- В свернутом состоянии сайдбар компактен (отображает только иконки или аккуратно убирается), а основной контейнер (`Main Canvas`) плавно расширяется с плавной аппаратной анимацией перехода (`transition-all duration-200`).
- На мобильных устройствах сайдбар функционирует в виде всплывающего ящика (Drawer) с затемненным бэкдропом.

### 2.3. Лаконичный индикатор синхронизации
- Статус синхронизации вынесен из шапки сайдбара и селектора рабочих пространств **в самую нижнюю часть боковой панели**.
- Оформлен как лаконичный индикатор: аккуратный зеленый пульсирующий светодиод (Cyber Emerald) + подпись «Синхронизировано» / время последнего сохранения.

### 2.4. Нижний глобальный виджет Quick Capture
- В глобальную оболочку приложения добавлен постоянный нижний плавающий виджет быстрого захвата (Quick Capture).
- Виджет зафиксирован в нижней части экрана (`fixed bottom-6 left-1/2 -translate-x-1/2 z-50`) и доступен во всех разделах приложения поверх контента.
- Для предотвращения наложения контента страницы снабжаются нижним отступом `pb-24` / `pb-28`.

## 3. Архитектура и техническое решение

### 3.1. Компоненты каркаса
- `src/components/layout/AppLayout.tsx`: Корневая обертка приложения, слушатель хоткея `Ctrl+B`, управление раскладкой.
- `src/components/layout/Sidebar.tsx`: Левая боковая панель с поддержкой состояния `isCollapsed`, обновленным пунктом «Заметки» и нижним индикатором синхронизации.
- `src/components/layout/Header.tsx`: Верхняя панель (строка поиска `⌘K`, системные уведомления, профиль). Дублирующие кнопки создания заметок и записей отсутствуют.
- `src/components/layout/QuickCaptureWidget.tsx` (или `src/components/common/QuickCaptureWidget.tsx`): Глобальный нижний виджет захвата мыслей.

### 3.2. Спецификация Sidebar
- **Верхняя часть:** Логотип `VoiceNotes AI`, кнопка сворачивания (`dock_to_left` / `Ctrl+B`), селектор «Личное пространство» (без дублирования статуса синхронизации).
- **Навигация:** Активные вкладки со шрифтом Inter / Geist («Главная», «Заметки», «Задачи», «Календарь», «AI Сводки», «Настройки»).
- **Нижняя часть:**
  - Лаконичный индикатор синхронизации: статусная точка (Cyber Emerald) + «Синхронизировано».
  - Прогресс-бар заполнения хранилища («16.4 / 20 ГБ»).
  - Карточка профиля пользователя («Алексей Орлов», Pro).

### 3.3. Спецификация Header (`h-16`)
- Поле быстрого поиска с бейджем горячей клавиши `⌘K`.
- Правая часть: бейдж текущей даты, центр уведомлений, аватар профиля. Дублирующиеся кнопки создания/записи в хедере отсутствуют.

### 3.4. Основная зона (`Main Canvas`)
- Динамический отступ слева (`pl-72` в развернутом виде, `pl-0` в свернутом виде) с CSS-переходом `transition-all duration-200`.
- Нижний отступ `pb-24` / `pb-28` для предотвращения перекрытия контента нижним Quick Capture виджетом.

- [ ] Раздел навигации переименован в «Заметки» (без приставки «и аудио») во всех элементах интерфейса и роутинга.

- [ ] Статус синхронизации вынесен в самую нижнюю часть сайдбара в виде аккуратного лаконичного индикатора и убран из шапки панели.
- [ ] Нижний глобальный виджет Quick Capture интегрирован в каркас приложения и доступен во всех разделах.
