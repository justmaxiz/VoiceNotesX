## 1. Цель
Внедрить плавные и премиальные микро-анимации в интерфейс (вдохновленные React Bits, Linear и Things 3), исключив статичность и дергания верстки.

---

## 2. Требования
1. **Каскадное появление (Staggered Fade-in):**
   - Плавное появление списков карточек задач и заметок при загрузке или смене фильтра (задержка 30-50 мс между элементами, мягкий opacity transition).
2. **Интеракции чекбоксов задач (Linear style):**
   - При клике на чекбокс — плавное перечеркивание текста (`line-through`) с одновременным мягким снижением прозрачности до 0.6 и зеленой индикацией выполнения.
3. **Анимация виджета записи:**
   - Пульсирующий мягкий неоновый контур (Border Glow) и плавная волнограмма при активном захвате звука в нижнем виджете Quick Capture.
4. **Переходы между экранами (View Transitions):**
   - Мягкий кросс-фейд (Fade transition 150–200 мс) при навигации по хэш-маршрутам.
5. **Hover-эффекты:**
   - Подсвечивание границ карточек (`border-primary/40` или `glow-violet`) и мягкая смена фона на `surface-container-high`.

---

## 3. Архитектура и Реализация
- Файл: `src/styles/animations.css` или Tailwind утилиты классов (`transition-all duration-200 ease-out`).
- Переиспользуемые хуки или компоненты-обертки для анимированных списков и чекбоксов.

---

## 4. Критерии приёмки (DoD)
- [x] Чекбоксы задач анимируются плавно без рывков.
- [x] Переходы между экранами происходят с мягким фейдом.
- [x] Виджет записи подсвечивается живым пульсирующим контуром.
- [x] Карточки при наведении плавно подсвечивают границы.
- [x] Все тесты проходят успешно, производительность 60 FPS.
