## 1. Цель задачи
Реализовать скачивание выбранной заметки в виде чистого Markdown файла (`.md`) с метаданными (Frontmatter) и обеспечить поддержку всех глобальных клавиатурных сочетаний.

---

## 2. Техническое решение

### 2.1. Утилита экспорта `exportNoteAsMarkdown` (`src/lib/export.ts`)
- Генерация содержимого:
  ```markdown
  ---
  title: "${note.title}"
  date: "${note.createdAt}"
  category: "${note.categoryTag}"
  priority: "${note.priority}"
  type: "${note.type}"
  ---

  # ${note.title}

  ${note.description || ''}

  ${note.transcriptText ? `> **Голосовая расшифровка:**\n> ${note.transcriptText}\n` : ''}

  ${checklistMarkdown}
  ```
- Инициирование скачивания: создание виртуального `<a>` с атрибутом `download="${slugify(note.title)}.md"` и ссылкой `URL.createObjectURL(blob)`.

### 2.2. Карта глобальных хоткеев
| Хоткей | Действие |
| :--- | :--- |
| `Space` | Старт / Пауза голосовой записи |
| `⌘K` / `Ctrl+K` | Открыть командную строку поиска |
| `Enter` (в строке ввода) | Сохранить локальную задачу |
| `⌘Enter` / `Ctrl+Enter` | Отправить на структурирование в ИИ |
| `Escape` | Закрыть модальное окно / отменить запись |

---

## 3. Критерии приемки (Definition of Done)
1. Клик по кнопке «Экспорт в .md» в карточке заметки моментально скачивает валидный файл `.md`.
2. Файл корректно открывается в Obsidian, VS Code, Notion и стандартных текстовых редакторах.
3. Все хоткеи из таблицы работают безотказно.
