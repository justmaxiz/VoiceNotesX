# TASK-70: Сохранённая ИИ-сводка в карточке главной страницы

- **ID:** `TASK-70`
- **Блок:** 10. ИИ-сводки с проверяемыми наблюдениями
- **Статус:** Реализовано; автоматические проверки выполнены
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-68`, `TASK-69`

## Цель

Показывать на главной странице компактную версию того же дневного отчёта, который доступен в разделе сводок, без отдельной генерации и расхождения чисел.

## Объём работ

- Убрать `generateDigestData('today', items)` из `DashboardOverview`; использовать общее состояние TASK-68.
- Адаптировать `DailySummaryCard` и совместимый экспорт `DailyAiSummaryWidget`: краткий итог, до трёх направлений и, если уместно, одно наблюдение внимания.
- Показать актуальное время среза/метку stale. Не обозначать все заметки аккаунта как проанализированные за день; использовать показатели покрытия данного отчёта.
- При ещё не созданном отчёте показывать реальные дневные факты и переход к генерации. При отказе ИИ — фактическую версию; при offline — последний снимок с временем.
- Кнопка открывает сегодняшний отчёт в разделе сводок с сохранением контекста; открытие карточки и страницы не вызывает LLM.
- Готовая новая версия отражается в обеих точках без перезагрузки и второго запроса. Сохранить настройку видимости модуля дашборда.
- Не менять независимо существующий алгоритм фокуса и показатели других dashboard widgets.

## Критерии приёмки

- Итог, источники, период и время совпадают с полным дневным отчётом.
- Нет локальной повторной генерации или второго LLM-вызова из dashboard render.
- Новый пользователь, stale, error и offline имеют читаемые компактные состояния.

## Проверки

- Изолированные тесты DashboardOverview/DailySummaryCard: общая версия, состояния, переход и выключенный модуль.
- Клиентская сборка; для локального UI полный Vitest не запускать.

## Результат реализации
