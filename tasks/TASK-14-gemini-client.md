# TASK-14: Сервис Google AI Studio (Gemini 2.0/2.5 Flash API Client)

- **ID:** `TASK-14`
- **Блок:** 4. ИИ-модуль (Google AI Studio Gemini Flash)
- **Статус:** Ожидает выполнения
- **Приоритет:** Критический (P0)
- **Зависимости:** `TASK-06`

---

## 1. Цель задачи
Разработать клиент для прямого взаимодействия с REST API Google AI Studio с поддержкой бесплатного ключа Gemini 2.0/2.5 Flash ($0 затрат) и безопасным хранением ключа в локальном хранилище браузера (BYOK).

---

## 2. Техническое решение

### 2.1. Клиент API (`src/lib/gemini.ts`)
- Эндпоинт:
  `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=${apiKey}`
- Механизм хранения ключа:
  - Проверка ключа в Zustand Store / `localStorage.getItem('voicenotes_gemini_key')`.
  - Возможность работы в Mock-режиме (если ключ не введен, приложение генерирует качественные детерминированные результаты локально, не блокируя работу).
- Обработка ошибок:
  - 429 Too Many Requests: понятное сообщение о превышении лимита 15 RPM.
  - 400/403 Invalid Key: подсветка ошибки с кнопкой перехода в настройки.

---

## 3. Критерии приемки (Definition of Done)
1. Успешная отправка текстового запроса и получение ответа от модели Gemini Flash.
2. Поддержка сохранения API-ключа пользователем.
3. Бесперебойная работа с локальным моком, если ключ еще не настроен.
