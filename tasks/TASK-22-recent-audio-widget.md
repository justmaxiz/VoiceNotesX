# TASK-22: Модульный виджет «Недавние аудиозаписи»

- **ID:** `TASK-22`
- **Блок:** 5. Главный экран и Виджеты (Дашборд / Обзор)
- **Статус:** Выполнено
- **Приоритет:** Средний (P2)
- **Зависимости:** `TASK-06`, `TASK-12`, `TASK-28`, `TASK-33`

---

## 1. Цель
Разработать виджет последних аудиозаписей как опциональный модуль дашборда, скрытый по умолчанию на главном экране для устранения визуального мусора, с возможностью включения пользователем через настройки модульного дашборда.

---

## 2. Требования

1. **Скрытие по умолчанию на главном экране:**
   - По умолчанию виджет «Недавние аудиозаписи» скрыт на дашборде (`recentAudio: false`).
   - Устраняется избыточный визуальный шум: внимание пользователя фокусируется на актуальной задаче дня, списке дел и чистых фактах продуктивности.

2. **Опциональный модуль в настройках модульного дашборда:**
   - Интеграция с системой настройки модульного дашборда (`TASK-33`) и разделом настроек (`TASK-28`).
   - В модалке/панели «Настроить виджеты» доступен переключатель для модуля «Недавние аудиозаписи».
   - Состояние видимости модуля персистентно сохраняется в конфигурации интерфейса пользователя (LocalStorage / IndexedDB).

3. **Функционал виджета при включении:**
   - Заголовок с иконкой аудиоволны `graphic_eq`: *«Недавние аудиозаписи»* и быстрая ссылка *«Смотреть все»* (переход в раздел «Заметки»).
   - Список последних 3–5 аудиозаписей пользователя с отображением названия, длительности (например, `0:42 мин`) и времени создания.
   - Компактная кнопка воспроизведения (Play/Pause) 24x24px слева от названия для быстрого предпрослушивания записи без смены экрана (`TASK-12`).

---

## 3. Архитектура и Реализация

- **Компонент:** `src/components/dashboard/components/RecentAudioWidget.tsx`.
- **Стейт модульности:**
  - `useDashboardConfigStore` (`src/store/dashboardConfigStore.ts`):
    - Свойство `modules.recentAudio: boolean` (значение по умолчанию: `false`).
    - Экшен `toggleModule('recentAudio')`.
- **Рендеринг:** В `DashboardOverview.tsx` виджет монтируется условно: `{modules.recentAudio && <RecentAudioWidget />}`.
- **Интеграция аудио:** хук `useAudioPlayer` для управления воспроизведением аудиодорожки (`TASK-12`).

---

## 4. Критерии приёмки (DoD)

- [ ] Виджет по умолчанию скрыт на главном экране дашборда и не создает визуального перегруза.
- [ ] В настройках модульного дашборда присутствует переключатель отображения «Недавние аудиозаписи».
- [ ] При включении тумблера виджет появляется в правой колонке дашборда и отображает последние аудиозаписи.
- [ ] Клик по компактной кнопке воспроизведения 24x24px проигрывает аудиозапись.
- [ ] Ссылка «Смотреть все» переключает на экран «Заметки».
- [ ] Настройка видимости сохраняется между перезагрузками страницы.
