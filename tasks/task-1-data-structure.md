# Задача 1: Структура данных и хранилище

## Описание
В рамках модернизации системы задач необходимо добавить поддержку времени начала (`startDate`). Существующее поле `deadline` будет использоваться как время окончания задачи.

## Требования
1. **Обновление типов:** В `src/types/` обновить интерфейс задачи, добавив опциональное/обязательное поле `startDate: Date` (или `number` timestamp в зависимости от текущей реализации).
2. **Обновление БД (Dexie):** Если требуется, обновить схему базы данных `IndexedDB`/`Dexie` для хранения нового поля `startDate`. Увеличить версию базы данных, если это необходимо.
3. **Обновление форм создания/редактирования:** В UI добавления задачи добавить возможность указывать время начала задачи (либо вычислять его неявно, если пользователь задает длительность).
4. **Миграция старых данных (опционально):** Если есть старые задачи, им нужно присвоить `startDate` (например, равный их `deadline` или `createdAt`), чтобы избежать ошибок при рендере.

## Критерии приемки
- Новая задача успешно сохраняется в БД с полями `startDate` и `deadline`.
- Старые задачи корректно считываются из БД без падения приложения.
