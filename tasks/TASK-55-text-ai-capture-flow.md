# TASK-55: Быстрый ввод с AI-панелью и повтором обработки

- **ID:** `TASK-55`
- **Блок:** 9. Облачный backend и ИИ-обработка ввода
- **Статус:** Реализовано; автоматические проверки пройдены
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-50`, `TASK-51`, `TASK-53`, `TASK-54`

## Цель

Отправлять каждую отправленную мысль или текст диктовки на AI endpoint и показывать результат в панели деталей со skeleton-состоянием.

## Контекст и связанные части проекта

`QuickCaptureWidget` сейчас сохраняет обычный ввод напрямую и запускает ИИ лишь по `Ctrl/⌘+Enter`. После записи `useSpeechRecognition` подставляет текст в то же поле. Панель `SlideOverDrawer` открывается только для сохранённых элементов.

## Объём работ

- Запускать AI-структурирование при обычной отправке текста и распознанной диктовки; сохранить исходный текст как транскрипт записи.
- Немедленно открыть drawer для временной записи и показывать мигающие skeleton-поля до ответа backend.
- При валидном ответе сохранить одну заметку через remote repository, заменить skeleton данными, а затем показать действие открытия детали.
- При ошибке сохранить введённый текст, показать причину и кнопку повтора; разрешить пользователю отдельно сохранить исходный текст без структурирования.
- Не сохранять короткий исходный микрофонный blob после обработки; хранить на backend получившуюся заметку/транскрипт.
- Блокировать повторную отправку того же запроса, пока текущая попытка активна; закрытие drawer не теряет текст и состояние повтора.

## Критерии приёмки

- `Enter` и кнопка отправки проходят через AI; пустой ввод не отправляется.
- Drawer открывается до ответа и содержит skeleton, затем показывает серверные поля без потери исходного текста.
- Сеть/provider error и пустой/невалидный результат оставляют ввод доступным для повтора; повторный успех создаёт одну запись.
- Сохранение исходного текста вручную не объявляет его AI-структурированным и не теряет его содержимое.

## Проверки

- Компонентные тесты пустого ввода, pending skeleton, успеха, таймаута, невалидного ответа, повтора и сохранения исходного текста.
- Проверить авторизованный API client и отсутствие прямого вызова Gemini из UI.
