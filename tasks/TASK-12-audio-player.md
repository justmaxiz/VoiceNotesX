# TASK-12: Компактный мини-аудиоплеер (Mini Play Button)

- **ID:** `TASK-12`
- **Блок:** 3. Аудио-движок и Нативный Голосовой Ввод
- **Статус:** Выполнено
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-09`

---

## 1. Цель
Разработать легковесный и минималистичный компонент мини-аудиоплеера для воспроизведения голосовых заметок в карточках и на дашборде, полностью исключив громоздкие волновые дорожки в пользу компактной кнопки Play (24x24px) рядом с метаданными.

---

## 2. Требования

### 2.1. Отказ от громоздких волновых дорожек
- Полностью убрать массивные визуализаторы волны, интерактивные дорожки скраббинга и перегруженные панели плеера из всех карточек заметок и блоков дашборда.
- Аудиозапись в карточке не должна смещать фокус с текста заметки и занимать лишнюю высоту.

### 2.2. Спецификация мини-кнопки Play
- Размер кнопки: строго **24x24px** (`w-6 h-6`).
- Расположение: непосредственно в строке метаданных рядом с датой и временем создания заметки / хронометражем (например: `14:20 · 0:45 [Play]`).
- Внешний вид:
  - Компактная скругленная кнопка (`rounded-full bg-surface-container-high hover:bg-primary text-on-surface hover:text-white transition-all`).
  - В состоянии покоя: мини-иконка воспроизведения (`play_arrow`, 14–16px).
  - При активном воспроизведении: иконка паузы (`pause`), деликатная кольцевая или точечная индикация проигрывания.
- Управление воспроизведением:
  - Мгновенный старт/пауза аудио при клике.
  - Автоматическая остановка воспроизведения любого другого трека в приложении при запуске нового (single active audio).

---

## 3. Архитектура и техническое решение

### 3.1. Компонент `MiniAudioPlayer.tsx` (`src/components/audio/MiniAudioPlayer.tsx`)
```typescript
interface MiniAudioPlayerProps {
  audioUrl?: string;
  duration?: number;
  className?: string;
  onEnded?: () => void;
}
```
- Использование легковесного HTML5 `<audio>` или глобального аудио-контроллера (Audio Playback Store):
  ```typescript
  const { currentAudioUrl, isPlaying, playAudio, pauseAudio } = useAudioStore();
  ```
- При клике:
  - Если данный `audioUrl` уже играет -> ставит на паузу.
  - Если играет другой трек или ничего не играет -> запускает воспроизведение текущего.

### 3.2. Интеграция в карточки заметок и виджеты
- Размещение в строке мета-информации карточки вместо устаревшего `AudioWaveformPlayer`:
  ```tsx
  <div className="flex items-center gap-2 text-xs text-text-outline">
    <span>14:32</span>
    <span>•</span>
    <span>{formatDuration(note.duration)}</span>
    {note.audioUrl && (
      <MiniAudioPlayer audioUrl={note.audioUrl} duration={note.duration} />
    )}
  </div>
  ```

## 4. Критерии приёмки (DoD)
- [ ] Громоздкие волновые дорожки полностью удалены из карточек заметок, Hero-карточки и виджетов дашборда.
- [ ] В карточках заметок с аудио присутствует компактная мини-кнопка Play размером ровно 24x24px рядом с датой/временем.
- [ ] Клик по мини-кнопке мгновенно воспроизводит аудио и меняет иконку на Pause; повторный клик ставит на паузу.
- [ ] Одновременно может воспроизводиться только один аудиофайл; при запуске нового предыдущий автоматически останавливается.
