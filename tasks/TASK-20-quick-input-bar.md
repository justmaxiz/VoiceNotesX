# TASK-20: Единый плавающий Quick Capture Widget

- **ID:** `TASK-20`
- **Блок:** 5. Главный экран и Виджеты (Глобальные элементы)
- **Статус:** Ожидает выполнения
- **Приоритет:** Критический (P0)
- **Зависимости:** `TASK-03`, `TASK-06`, `TASK-09`, `TASK-10`, `TASK-11`, `TASK-15`

---

## 1. Цель
Реализовать единый глобальный плавающий Quick Capture Widget в нижней части экрана для быстрого сбора мыслей и задач: ручной текстовый ввод, голосовая запись с динамической аудио-волнограммой прямо внутри виджета при записи и интеграция с вызовом из Канбан-доски.

---

## 2. Требования

1. **Глобальное позиционирование и оформление:**
   - Фиксированный плавающий бар по центру внизу экрана (`fixed bottom-6 left-1/2 -translate-x-1/2 z-50`).
   - Полупрозрачная капсула со стекломорфизмом (`rounded-2xl bg-surface-container/90 backdrop-blur-xl border border-outline-variant/30 shadow-2xl`).
   - Виджет отображается поверх всех экранов приложения, не перекрывая рабочий контент (контейнерам страниц в AppLayout задается нижний отступ `pb-28`).

2. **Ручной текстовый ввод мыслей и задач:**
   - Текстовое поле с плейсхолдером *«Быстрая мысль или задача... | Enter — сохранить»*.
   - Быстрый переключатель типа сущности (Задача / Заметка) прямо в строке виджета.
   - Нажатие `Enter`: мгновенное локальное сохранение задачи/заметки в IndexedDB через стейт.
   - Нажатие `⌘Enter` / `Ctrl+Enter`: отправка текста в Gemini Flash для интеллектуального автоструктурирования (парсинг чек-листов, тегов, дедлайна).

3. **Голосовой ввод и живая волнограмма внутри виджета:**
   - Интегрированная кнопка микрофона с цветовой индикацией состояния.
   - При активации записи (клик по микрофону или удержание клавиши `Space`):
     - Внутри корпуса виджета запускается плавная динамическая волнограмма громкости голоса (Canvas/SVG Waveform `TASK-10`) в реальном времени.
     - Мягкий светящийся контур виджета (Border Glow).
     - Живая расшифровка речи (Web Speech API STT `TASK-11`) транслируется прямо в текстовое поле с мягкой подсветкой промежуточных результатов.
   - Повторный клик или отпускание клавиши завершает запись и фиксирует текст.

4. **Интеграция с вызовом из Канбан-доски:**
   - При клике на «Создать новую» в выпадающем меню Канбан-доски (`TASK-25`) плавающий виджет автоматически раскрывается и фокусирует поле ввода.
   - Передача контекста целевой колонки (`targetColumn`: `'todo'`, `'focus'`, `'in_progress'`) для сохранения задачи сразу в нужный статус.
   - Автоматическая установка типа сущности `entityType: 'task'`.

## 3. Архитектура и Реализация

- **Компоненты:**
  - `src/components/layout/QuickCaptureWidget.tsx` (или `src/components/quick-capture/QuickCaptureWidget.tsx`) — корневой компонент плавающего виджета, интегрированный в AppLayout.
  - `src/components/audio/LiveWaveform.tsx` — компактный визуализатор звуковой волны внутри капсулы виджета (`TASK-10`).
- **Стейт-менеджмент (`useQuickCaptureStore`):**
  - **Поля:**
    - `isOpen: boolean` — состояние видимости/раскрытия виджета.
    - `entityType: 'task' | 'note'` — тип создаваемой сущности (по умолчанию `'task'`).
    - `recordingState: 'idle' | 'recording' | 'processing'` — состояние аудиозахвата.
    - `targetColumn: string | null` — колонка Канбан-доски для целевого сохранения задачи.
    - `text: string` — текущее значение поля ввода.
  - **Действия:**
    - `openQuickCapture(options?: { targetColumn?: string; entityType?: 'task' | 'note'; initialText?: string })` — открытие с заданными параметрами.
    - `closeQuickCapture()` — закрытие/сворачивание виджета.
    - `setEntityType(type: 'task' | 'note')` — смена типа сущности.
    - `startRecording()` / `stopRecording()` — управление сессией записи.
    - `setText(text: string)` — обновление текстового буфера.
    - `submitContent()` — сохранение в базу (Dexie / Zustand).
- **Интеграция с аудио:** хуки `useAudioRecorder` и `useSpeechRecognition`.

## 4. Критерии приёмки (DoD)

- [ ] Виджет зафиксирован внизу экрана как единая плавающая капсула со стекломорфизмом и доступен на всех экранах приложения.
- [ ] Ручной ввод мыслей и задач сохраняет сущность по `Enter` мгновенно без задержек.
- [ ] Доступен быстрый переключатель между типами сущностей «Задача» и «Заметка».
- [ ] При записи голоса живая анимация аудио-волны отображается прямо внутри корпуса виджета синхронно с речью.
- [ ] Распознанный текст диктовки поступает в поле ввода в реальном времени с подсветкой.
- [ ] Клик по пункту «Создать новую» на Канбан-доске активирует и фокусирует Quick Capture Widget с привязкой к выбранной колонке.
- [ ] Нажатие `⌘Enter` / `Ctrl+Enter` запускает Gemini Flash структурирование.
