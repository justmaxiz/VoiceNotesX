# TASK-29: Глобальная командная палитра поиска (`⌘K` Command Palette)

- **ID:** `TASK-29`
- **Блок:** 7. Глобальный UX, Хоткеи и Экспорт
- **Статус:** Ожидает выполнения
- **Приоритет:** Критический (P0)
- **Зависимости:** `TASK-03`, `TASK-08`

---

## 1. Цель задачи
Реализовать модальное окно глобального быстрого поиска и команд (Command Palette), открывающееся по клику на поиск в хедере или нажатию сочетания клавиш `⌘K` / `Ctrl+K`.

---

## 2. Техническое решение

### 2.1. Компонент `CommandPaletteModal.tsx` (`src/components/ui/CommandPaletteModal.tsx`)
- Горячие клавиши вызова:
  - `(event.metaKey || event.ctrlKey) && event.key === 'k'`
  - Закрытие по `Escape`.
- Элементы интерфейса:
  - Поле ввода с автофокусом и иконкой `search`.
  - Секция быстрых команд:
    - `Начать запись голоса [Space]`
    - `Создать новую задачу`
    - `Перейти в календарь`
  - Секция результатов поиска:
    - Интерактивный вывод найденных заметок и задач с подсвеченными совпадениями.
    - Перемещение стрелками `↑` / `↓` и выбор по `Enter`.

---

## 3. Критерии приемки (Definition of Done)
1. Нажатие `⌘K` / `Ctrl+K` в любом месте приложения мгновенно открывает модалку.
2. Поиск выводит релевантные задачи и заметки по мере ввода текста (< 3 мс).
3. Нажатие `Enter` на найденной задаче открывает ее детали или переходит в нужный раздел.
