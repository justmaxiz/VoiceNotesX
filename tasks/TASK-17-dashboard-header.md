# TASK-17: Шапка дашборда и динамическое приветствие

- **ID:** `TASK-17`
- **Блок:** 5. Главная Страница (Дашборд / Обзор)
- **Статус:** Выполнено
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-03`, `TASK-06`

---

## 1. Цель
Реализовать сфокусированную верхнюю секцию дашборда с динамическим персонализированным приветствием, текущей датой и статусом дня, исключив дублирующиеся кнопки создания заметок и записей в пользу чистоты интерфейса.

---

## 2. Требования

### 2.1. Исключение дублирующихся кнопок
- **Убрать кнопки «Новая заметка» и «Запись» / «Начать запись»** из шапки дашборда и хедера приложения.
- Создание заметок и аудиозапись централизованы в нижнем глобальном виджете Quick Capture (`TASK-20`) и вызываются глобальными хоткеями (`Space`, `⌘K`), что делает кнопки в шапке избыточными.
- Убрать дублирующийся индикатор синхронизации из шапки дашборда (синхронизация централизована внизу сайдбара по `TASK-03`).

### 2.2. Сохранение ключевых информационных блоков
1. **Динамическое приветствие:**
   - Автоматически адаптируется под текущее время суток:
     - Утро (05:00–11:59): «Доброе утро, Александр»
     - День (12:00–17:59): «Добрый день, Александр»
     - Вечер (18:00–22:59): «Добрый вечер, Александр»
     - Ночь (23:00–04:59): «Доброй ночи, Александр»
   - Шрифт: плотный, контрастный гротеск Inter / Geist с легким неоновым акцентом.
2. **Форматированная дата:**
   - Отображение текущего дня и месяца на русском языке (например: *«Пятница, 4 октября»*).
3. **Статус дня и продуктивности:**
   - Лаконичный бейдж со статусом активности (например, `3 сессии обработаны AI` цвета Cyber Emerald или `4 из 6 задач на сегодня выполнено`).
4. **Переключатель видов:**
   - Компактный сегментированный контрол для переключения раскладки задач дня («Список» / «Доска»).

---

## 3. Архитектура и техническое решение

### 3.1. Компонент `DashboardHeader.tsx` (`src/components/dashboard/components/DashboardHeader.tsx`)
- Определение времени и динамического приветствия:
  ```typescript
  export function getGreeting(userName: string = 'Александр'): string {
    const hour = new Date().getHours();
    if (hour >= 5 && hour < 12) return `Доброе утро, ${userName}`;
    if (hour >= 12 && hour < 18) return `Добрый день, ${userName}`;
    if (hour >= 18 && hour < 23) return `Добрый вечер, ${userName}`;
    return `Доброй ночи, ${userName}`;
  }
  ```
- Форматирование даты:
  ```typescript
  const todayFormatted = new Intl.DateTimeFormat('ru-RU', {
    weekday: 'long',
    day: 'numeric',
    month: 'long',
  }).format(new Date());
  ```
- Очищенный интерфейс пропсов:
  ```typescript
  export interface DashboardHeaderProps {
    userName?: string;
    dateText?: string;
    aiSessionsText?: string;
    viewMode: ViewMode;
    onViewModeChange: (mode: ViewMode) => void;
  }
  ```
- Разметка шапки:
  - Левая колонка: приветствие H1 (`text-2xl font-semibold tracking-tight text-on-surface`), под ним форматированная дата и статус дня.
  - Правая колонка: переключатель видов «Список / Доска». Дублирующиеся кнопки «+ Новая заметка» и «Начать запись [Space]» удалены.

- [x] Текущая дата и статус дня четко отображаются с правильной русской локализацией.
