# TASK-52: Однократный перенос локальных заметок в аккаунт

- **ID:** `TASK-52`
- **Блок:** 9. Облачный backend и ИИ-обработка ввода
- **Статус:** Реализовано; автоматические проверки пройдены
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-48`, `TASK-48A`, `TASK-49`, `TASK-50`, `TASK-51`

## Цель

Перенести пользовательские записи из существующей IndexedDB в backend без потери данных и без повторного создания при прерывании.

## Контекст и связанные части проекта

`VoiceNotesDB` хранит `items` и `audioSessions`, включая аудиоблобы; `seedDatabase()` добавляет локальные демонстрационные записи. После перехода на backend пользовательские заметки должны быть доступны на других клиентах.

## Объём работ

- При первом входе проверить локальную базу и предложить/запустить однократную миграцию пользовательских записей.
- Переносить заметки и аудиометаданные пакетами; существующие записи с аудио загрузить в закрытое хранилище и применить к исходникам срок 14 дней.
- Не загружать стандартные seed-записи как персональные; отличать их по известному механизму seed data.
- Сделать импорт повторяемым: прерывание, повторы и повторный вход не создают дубли.
- Добавить серверный endpoint импорта с уникальным ключом `(ownerId, legacyId)`; он использует репозиторий PostgreSQL и файловый адаптер, переносит существующее аудио без повторного AI-анализа и проверяет лимиты 100 МБ / 2 часа до записи.
- Сохранять локальную копию до подтверждения сервером количества/ID импортированных записей; после завершения убрать локальные пользовательские записи и аудиоблобы.
- Показать прогресс, ошибки отдельных пакетов и возможность продолжить миграцию.

## Критерии приёмки

- Каждая пользовательская локальная запись после миграции доступна из backend под тем же аккаунтом.
- Повторный запуск не дублирует записи; сбой до подтверждения не удаляет исходную локальную копию.
- Seed data не попадает в аккаунт как пользовательские заметки.
- После подтверждённого завершения IndexedDB не является источником пользовательских заметок или долговременного аудио.

## Проверки

- Тесты миграции пустой базы, базы с заметками, прерывания, повторного запуска, seed data и аудиоблобов.
- Тест сценария миграции через API с подтверждением владельца.
- Полный Vitest и build, так как затронуты типы, store и IndexedDB.
