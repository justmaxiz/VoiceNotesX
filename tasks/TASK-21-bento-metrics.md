# TASK-21: Bento-блок продуктивности (Метрики дня)

- **ID:** `TASK-21`
- **Блок:** 5. Главный экран и Виджеты (Дашборд / Обзор)
- **Статус:** Выполнено
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-06`

---

## 1. Цель
Реализовать Bento-карточки чистых фактологических метрик продуктивности дня («Выполнено X из Y» и «В плане Z») на дашборде без псевдосравнений и бессмысленного информационного шума, с динамическим прогресс-баром и легкой анимацией завершения при закрытии 100% задач дня.

---

## 2. Требования

1. **Сохранение карточек на дашборде:**
   - Карточки «Выполнено» и «В плане» сохраняются в верхнем Bento-блоке правой колонки дашборда.
   - Чистый, строгий стиль Obsidian Lumina с полупрозрачным фоном (`bg-surface-container border border-outline-variant/30 rounded-2xl p-4`).

2. **Полное удаление сравнительного текста:**
   - **УДАЛИТЬ** бессмысленный текст «+14% к среде», «+34% к прошлой неделе» и любые сравнения с прошлыми днями.
   - Исключить любые псевдо-метрики динамики — отображать только достоверные фактические данные текущего рабочего дня.

3. **Отображение чистого факта дня:**
   - **Карточка «Выполнено»:**
     - Заголовок с иконкой `check_circle` цвета Cyber Emerald (`text-secondary`).
     - Крупная цифра факта дня: **«Выполнено X из Y»** (динамически рассчитывается из массива задач текущего дня: выполненные / всего задач дня).
     - Сегментированный или сплошной прогресс-бар выполнения задач (`bg-secondary/20` с полосой `bg-secondary`).
   - **Карточка «В плане»:**
     - Заголовок с иконкой блокнота `assignment` цвета Electric Violet (`text-primary`).
     - Крупная цифра факта дня: **«В плане Z»** (количество оставшихся незавершенных задач на сегодня).
     - Компактный бейдж приоритета (например, `N в высоком фокусе`) без сравнительного шума.

4. **Анимация завершения при закрытии всех задач дня:**
   - При переходе последней запланированной задачи дня в статус «выполнено» (`totalCount > 0 && completedCount === totalCount`):
     - Воспроизводится легкая анимация завершения: деликатный изумрудный импульс/свечение карточки (Emerald Glow) и плавная микро-анимация иконки `check_circle`.
     - Анимация ненавязчивая, длится 1–1.5 с, не блокирует пользовательский интерфейс.

---

## 3. Архитектура и Реализация

- **Компонент:** `src/components/dashboard/components/ProductivityMetrics.tsx` (Bento-блок метрик дня).
- **Интерфейс компонента:**
  ```typescript
  export interface ProductivityMetricsProps {
    totalCount: number;
    completedCount: number;
    plannedCount: number;
  }
  ```
  *(Все устаревшие пропсы `productivityDeltaText` и `estimatedHours` удаляются).*
- **Селекторы стейта (`useTaskStore`):**
  - `todayTotal`: общее количество задач с датой на сегодня.
  - `todayCompleted`: количество выполненных задач на сегодня.
  - `todayPending`: количество незавершенных задач (`todo`, `focus`, `in_progress`).
  - `isAllDone`: булевый флаг (`todayTotal > 0 && todayCompleted === todayTotal`).
- **Анимация успеха:** использование CSS-анимации `@keyframes successGlow` или микро-анимации Framer Motion при переключении `isAllDone` в `true`.

- [ ] Карточки «Выполнено» и «В плане» сохранены на главном экране дашборда.
- [ ] В обеих карточках полностью удален текст «+14% к среде» и любые сравнительные проценты с прошлыми днями.
- [ ] Карточка «Выполнено» отображает чистый факт дня: «Выполнено X из Y» с прогресс-баром.
- [ ] Карточка «В плане» отображает чистый факт дня: «В плане Z».
- [ ] Метрики и прогресс-бар реактивно пересчитываются при изменении статуса задач в реальном времени.
- [ ] При закрытии всех задач дня (100%) срабатывает легкая ненавязчивая анимация завершения.
