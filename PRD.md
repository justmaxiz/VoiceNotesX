## 1. Введение и Видение Продукта

### 1.1. Философия и назначение системы
**VoiceNotes AI** — это легковесный, реактивный и строгий персональный воркспейс для заметок, задач и планирования. 

> [!IMPORTANT] **Ключевой сдвиг концепции:**  
> **Голосовой ввод — это исключительно удобный способ ввода (Input Method)**, а не отдельная сущность или изолированная иерархия. Приложение строится вокруг **лаконичного текста, четких задач и структурированных действий**. Аудиозапись является фоновым исходником, а не центром интерфейса. Пользователю не навязываются аудио-плееры и волнограммы на каждом шагу: фокус держится на тексте, выжимке сути и выполнении дел.

### 1.2. Проблемы, устраняемые версией 2.5:
1. **Визуальный перегруз:** Ликвидированы лишние декоративные блоки (бутафорские карточки синхронизации устройств, навязчивые аудиоплееры на пол-экрана, бессмысленные псевдо-метрики вроде «+14% к среде»).
2. **Фрагментация действий:** Вместо дублирования кнопок «Новая заметка» и «Запись» по всему экрану создан **единый плавающий Quick Capture Widget**.
3. **Нечитаемость и слабая типографика:** Исправлены контрасты в календаре (никакого фиолетового на фиолетовом) и заменены раздутые декоративные шрифты меню на строгий читаемый системный гротеск (Golos Text).
4. **Технический мусор в настройках:** Экран настроек избавлен от дебаг-панелей (статус IndexedDB/MiniSearch) и формы ввода API-ключа. Ключ встроен в окружение, пользователю доступны понятные режимы («Быстрый» и «Глубокий анализ»), экспорт данных и управление устройствами.

## 2. Архитектура и Технологический Стек

### 2.1. Стек технологий
- **Фреймворк:** **React 19 + TypeScript (strict: true) + Vite**.
- **Стилизация:** **Tailwind CSS v4** с дизайн-системой **Obsidian Lumina 2.0**.
- **Типографика:** Системный интерфейсный шрифт **Golos Text** для меню, таблиц и карточек; моноширинный **JetBrains Mono** для таймингов и шорткатов.
- **Анимации и микро-интеракции:** Интеграция паттернов **React Bits** (Staggered Fade-in, border glow, linear-style checkbox strikes, view transitions).
- **Локальное хранилище (Local-First):** **IndexedDB** (Dexie.js) с Live Queries + **MiniSearch** для полнотекстового поиска (< 3 мс).
- **Стейт-менеджмент:** **Zustand** (хранилище навигации, фильтров, состояния сайдбара и модальных окон).
- **Голосовой ввод:**
  - Захват звука: **MediaRecorder API** (`audio/webm;codecs=opus`).
  - Локальный STT: **Web Speech API** с потоковой подсветкой распознаваемых слов.
  - Живая волна: анимируется **исключительно внутри виджета записи** во время диктовки.
- **ИИ-ядро:** серверные адаптеры AI-провайдеров с предустановленными режимами:
  - *Режим «Быстрый»*: моментальная очистка, форматирование и извлечение задач (< 0.6 сек).
  - *Режим «Глубокий анализ (Pro)»*: суммаризация больших встреч, анализ зависимостей задач и ежедневный дайджест.
- **Backend:** отдельный Node.js 24 LTS + TypeScript + Fastify 5 сервер с версионированным REST API `/api/v1`, авторизацией, PostgreSQL, закрытым хранением аудио, текстовым/аудио AI и сохраняемыми сводками. Вечерний scheduler/worker работают на сервере; контракт периодов, фактов, источников и ограничения первой версии описаны в `docs/SUMMARY-CONTRACTS.md`. Production использует Alice/SpeechKit, development — Gemini на синтетических данных.
- **Серверные данные:** PostgreSQL для пользователей, сессий, заметок и аудиометаданных; исходные аудиофайлы — в закрытой папке backend. В production база, аудио и резервные копии размещаются в РФ. Авторизация обслуживается Node API. Короткие аудиозапросы удаляются после обработки, загруженные файлы — через 14 дней; текстовые результаты сохраняются.
- **AI-провайдеры (целевое устройство):** Gemini используется только в development на синтетических данных. Production использует Alice AI через прямой API Yandex AI Studio; production аудио сначала расшифровывается через SpeechKit, затем текст анализируется Alice. Ключи хранятся только на сервере.

## 3. Дизайн-система «Obsidian Lumina 2.0»

### 3.1. Исправленная цветовая палитра и читаемость
- **Фон поверхностей:** Глубокий обсидиановый (`#121317`, `#1a1b20`, `#1f1f24`).
- **Текст:** Основной светлый текст `#e3e2e8` (`text-on-surface`) с контрастом к фону **> 12:1** (WCAG AAA).
- **Календарь (Критическое исправление):**
  - Подложки событий: полупрозрачные темные контейнеры с чистым белым/светло-серым текстом.
  - Категории: тонкие цветные вертикальные маркеры слева (Emerald `#4edea3` для релизов, Amber `#ffb74d` для ревью, Cyan `#4fc3f7` для отчетов).
  - Никакого фиолетового текста на темном фоне.
- **Навигация:** Сайдбар оформлен строгим шрифтом Golos Text (Medium 500), отделен четкой вертикальной линией `border-r border-surface-container-high/50` и поддерживает сворачивание (`Ctrl+B`).

## 4. Архитектура Интерфейса и Навигация

### 4.1. Структура разделов
1. **Главная / Обзор (`#overview`):** Лаконичный модульный дашборд фокуса дня.
2. **Заметки (`#notes`):** Хаб текстовых заметок с быстрым поиском, фильтрами по тегам и компактным плеером исходника.
3. **Задачи (`#tasks`):** Канбан-доска («К выполнению», «В процессе», «Завершено») с выпадающим меню создания.
4. **Календарь (`#calendar`):** Контрастное расписание дел и дедлайнов на неделю/месяц.
5. **AI Сводки (`#ai-summaries`):** Аналитические дайджесты дня/недели.
6. **Настройки (`#settings`):** Управление профилем, внешним видом, устройствами и экспортом данных.

## 5. Спецификация Экранов и Виджетов

### 5.1. Главный экран (Dashboard Overview)
- **Шапка (Header):** Приветствие («Добрый вечер, Александр»), дата, компактный статус задач на день. Убраны дублирующие кнопки записи.
- **Виджет «Текущая активная задача»:** Заменяет громоздкий плеер. Отображает главную приоритетную задачу, дедлайн, 2–3 ключевых подзадачи с чекбоксами и кнопку завершения.
- **Список задач дня:** Поддержка фильтров («Все», «Срочные», «Голосовые»), компактный вид, плавное зачеркивание при выполнении.
- **Метрики дня:** 
  - Карточка «Выполнено: X из Y» с сегментным прогресс-баром.
  - Карточка «В плане: Z задач».
  - **УДАЛЕНО:** надписи «+14% к среде» и псевдо-сравнения.
  - Легкая анимация при закрытии 100% задач дня.
- **Модульность:** Пользователь может через меню настройки дашборда скрывать или включать блоки (например, опциональный блок «Недавние аудиозаписи»).
- **УДАЛЕНО С ГЛАВНОЙ:** Карточка «Синхронизированное рабочее пространство» (перенесена в Настройки).

### 5.2. Единый плавающий Quick Capture Widget
- Расположен в нижней части экрана как фиксированный плавающий бар.
- Поле для быстрого набора текста мыслей и задач (Enter для сохранения).
- Кнопка микрофона:
  - При нажатии/удержании Space активируется режим диктовки прямо внутри виджета.
  - Отображается плавная динамическая волнограмма громкости голоса.
  - Текст транскрипции появляется в реальном времени с мягкой подсветкой.
- Интеграция с Канбаном: при выборе «Создать задачу» на Канбан-доске активируется и выдвигается данный виджет.

### 5.3. Карточки заметок и задач
- **Устранение пустот и троеточий:** Карточка имеет аккуратную фиксированную плотность, показывает полный заголовок (до 2 строк) и структурированный сниппет сути (2–3 строки) без обрезки посередине фразы.
- **Аудио-исходник:** Представлен аккуратной мини-кнопкой Play (24x24px) рядом с датой. Никаких 24 волновых полос на карточках.
- **Slide-over Drawer (Правая шторка):** По клику на любую карточку с правого края плавно выезжает панель для детального чтения, форматирования текста, работы с чекбоксами и прослушивания исходника.
- **Режимы отображения:** Переключатель между компактным списком (List View) и сеткой карточек (Grid View).

### 5.4. Канбан-доска задач
- Кнопка «+ Добавить задачу» в заголовке колонки открывает выпадающее меню (попап):
  1. *«Создать новую»* — фокусирует нижний Quick Capture виджет.
  2. *«Добавить из существующих»* — открывает модальное окно выбора нераспределенных заметок для конвертации в задачу.
- Колонки имеют пустые плейсхолдеры («Перетащите задачи сюда»), если в них нет элементов.

### 5.5. Экран настроек (Settings Page)
- **УДАЛЕНО:** форма ручного ввода Gemini API Key и технический блок статуса IndexedDB / FTS.
- **Разделы настроек:**
  1. **Профиль:** Имя, аватар, статус лицензии/подписки.
  2. **AI Движок:** Переключатель режимов:
     - *«Быстрый»* (включен по умолчанию, мгновенная обработка).
     - *«Глубокий анализ»* (Pro-подписка, углубленные выжимки и дайджесты).
     - Переключатель стиля саммари: «Кратко», «Подробно», «План действий».
  3. **Внешний вид:** Тема (тёмная / системная), выбор плотности шрифта.
  4. **Устройства и Синхронизация:** Список привязанных устройств (MacBook, iPhone), дата последней синхронизации, ручная кнопка «Синхронизировать сейчас».
  5. **Управление данными:** Кнопки «Экспорт всех заметок в Markdown / ZIP / JSON» и «Очистить локальный кэш».

## 6. Требования к Анимациям (React Bits / Smooth Motion)

1. **Появление контента:** Плавный Staggered Fade-in карточек и списков при загрузке или фильтрации (без дергания сетки).
2. **Чекбоксы задач:** Плавная анимация перечеркивания текста с постепенным затуханием прозрачности (стиль Linear / Things 3).
3. **Запись голоса:** Динамическая аудио-волна и светящийся мягкий контур (Border Glow) виджета записи.
4. **Переходы между экранами:** Плавный кросс-фейд (Fade transition 150–200 мс).
5. **Интеракции элементов:** Мягкое изменение фона `surface-container-high` и подсветка границ при hover.
