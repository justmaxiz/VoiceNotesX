# TASK-18: Динамический виджет «Текущая активная задача» (Focus Hero Widget)

- **ID:** `TASK-18`
- **Блок:** 5. Главная Страница (Дашборд / Обзор)
- **Статус:** Выполнено
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-06`, `TASK-12`

---

## 1. Цель
Переработать Hero-карточку дашборда из громоздкого аудиоплеера в динамический компактный виджет «Текущая активная задача» («В фокусе»), предназначенный для удержания внимания на ключевом приоритете дня, контроля дедлайна и быстрого закрытия подзадач.

---

## 2. Требования

### 2.1. Отказ от громоздкого аудиоплеера
- Полностью убрать из Hero-карточки гигантский аудиоплеер, массивную визуализацию звуковой волны и большие цитаты транскрипта (`AudioWaveformPlayer`).
- Если у активной задачи есть прикрепленная аудиозапись, отображать исключительно мини-кнопку Play (24x24px) рядом с метаданными в соответствии с `TASK-12`.

### 2.2. Состав и функционал виджета «Текущая активная задача»
1. **Заголовок и статус фокуса:**
   - Пульсирующий мятный бейдж `В фокусе` (`bg-secondary-container text-on-secondary`).
   - Название приоритетной задачи (контрастный плотный шрифт Inter / Geist).
   - Тег категории (например, `Работа`) и маркер срочности (`! Высокий приоритет`).
2. **Дедлайн:**
   - Четкое указание времени завершения (например, `Дедлайн: сегодня до 21:00`).
3. **Ключевые подзадачи:**
   - Интерактивный чек-лист из 2–4 актуальных шагов выполнения задачи.
   - Возможность пошаговой отметки подзадач прямо внутри виджета с плавной анимацией вычеркивания в стиле Linear (`linear-style checkbox strike`).
4. **Чекбокс / кнопка завершения:**
   - Главный чекбокс / кнопка выполнения всей задачи (`✓ Завершить`).
   - При завершении: мгновенное обновление состояния задачи, анимация конфетти (`canvas-confetti`) и автоматический выбор следующей приоритетной задачи.
5. **Состояние отсутствия задач (Empty State):**
   - При завершении всех приоритетных задач дня отображается аккуратное поздравительное состояние «Все задачи в фокусе выполнены!».
6. **Компактные габариты:**
   - Виджет не должен доминировать над остальным контентом дашборда по высоте; аккуратная карточка в стиле `glass-panel` с мягким неоновым свечением границы (`border-glow`).

---

## 3. Архитектура и техническое решение

### 3.1. Компонент `FocusHeroCard.tsx` (`src/components/dashboard/components/FocusHeroCard.tsx`)
```typescript
interface FocusHeroCardProps {
  task?: Task;
  onCompleteTask?: (taskId: string) => void;
  onToggleSubtask?: (taskId: string, subtaskId: string) => void;
}
```
- Получение активной задачи из стейта:
  ```typescript
  const focusTask = useTaskStore(state => 
    state.tasks.find(t => t.isFocus && !t.isCompleted) || state.tasks.find(t => !t.isCompleted)
  );
  ```
- Рендеринг подзадач с Linear-style вычеркиванием:
  ```tsx
  <div className="space-y-1.5 my-3">
    {focusTask.subtasks?.map(sub => (
      <label key={sub.id} className="flex items-center gap-2 cursor-pointer group text-sm">
        <input 
          type="checkbox" 
          checked={sub.isCompleted} 
          onChange={() => toggleSubtask(focusTask.id, sub.id)}
          className="rounded border-outline bg-surface-container text-secondary focus:ring-0" 
        />
        <span className={sub.isCompleted ? 'line-through text-text-outline transition-all' : 'text-on-surface'}>
          {sub.title}
        </span>
      </label>
    ))}
  </div>
  ```
- Аудио-ссылка:
  - При наличии `focusTask.audioUrl` рендерится `<MiniAudioPlayer audioUrl={focusTask.audioUrl} />` (24x24px) рядом со строкой дедлайна.
