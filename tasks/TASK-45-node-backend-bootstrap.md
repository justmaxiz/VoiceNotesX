# TASK-45: Базовый Node.js backend и API-каркас

- **ID:** `TASK-45`

- **Статус:** Реализовано; автоматические проверки пройдены
- **Приоритет:** Критический (P0)
- **Зависимости:** Нет

## Цель

Создать отдельное Node.js API для веб-клиента и будущих Expo-клиентов. В этой задаче реализуется только фундамент сервера, без базы, авторизации и AI-эндпоинтов.

## Контекст и связанные части проекта

Корень проекта содержит React/Vite-клиент; текущая реализация хранит данные в Dexie/IndexedDB. Серверный пакет находится в `server/`, запускается независимо от клиента и начинает API с `/api/v1`.

## Объём работ

- Использовать Node.js 24 LTS, TypeScript и Fastify 5; команды клиента и сервера должны оставаться независимыми.
- Проверять `NODE_ENV`, `PORT` и `CORS_ORIGINS`; локальные значения задаются в `server/.env`, production origin перечисляются явно и используют HTTPS.
- Добавить `GET /api/v1/health`, который не зависит от БД или AI-сервиса, безопасные JSON-ошибки и ограничение размера обычного HTTP body.
- Хранить локальные секреты только в env-файле, исключённом из Git. Не добавлять ключи AI или базы в Vite-конфигурацию.
- Документировать локальную установку, сборку и запуск. В архитектурных документах различать текущий Dexie-клиент и целевую серверную синхронизацию.

## Критерии приёмки

- `npm run backend:build` собирает сервер независимо от Vite.
- `npm run backend:dev` запускает сервер, а `GET /api/v1/health` возвращает `{ "status": "ok" }`.
- Неверный порт, wildcard CORS и production origin без HTTPS приводят к понятной ошибке конфигурации.
- Production не стартует без явного `CORS_ORIGINS`; ключи провайдера не требуются, пока AI-маршрут не реализован.
- `server/.env` не отслеживается Git; клиентская сборка не включает серверные env-секреты.

## Проверки

- Собрать backend через `npm run backend:build`.
- Запустить локальный сервер и выполнить HTTP smoke check для health endpoint.
- Проверить валидность примера конфигурации и production-валидацию списка origin.
