# TASK-53: Единые заметки и представления по расписанию

- **ID:** `TASK-53`
- **Блок:** 9. Облачный backend и ИИ-обработка ввода
- **Статус:** Реализовано; автоматические проверки пройдены
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-47`, `TASK-51`

## Цель

Убрать отдельное создание сущностей «Заметка» и «Задача»: любой ввод создаёт одну заметку, которая появляется в представлении запланированных задач после добавления даты или времени.

## Контекст и связанные части проекта

Переключатель типа есть в `QuickCaptureWidget`; поле `Item.type` используется заметками, Kanban, фильтрами, поиском и drawer. API использует единый контракт `Note` из `TASK-47`.

## Объём работ

- Удалить переключатель «Задача/Заметка» из формы быстрого ввода и убрать ветки создания разных типов.
- Сделать `NotesPage`, Kanban и календарь представлениями одной записи: unscheduled записи остаются в заметках; запись с явно заданным расписанием отображается в запланированных задачах/календаре.
- Разрешить добавить или изменить дату/время из панели деталей; изменение расписания перемещает запись между представлениями, не создавая копию.
- Сохранить статусы, приоритет, чек-лист, теги, поиск и открытие одной и той же записи из разных представлений.
- Удалить AI-зависимое переключение типа из клиентской модели; не считать автоматическую классификацию текста заменой расписания.

## Критерии приёмки

- Форма ввода больше не предлагает отдельный тип заметки или задачи.
- Новая запись без даты/времени отображается как заметка; добавление расписания показывает ту же запись в запланированных задачах/календаре.
- Удаление расписания возвращает запись в несрочное представление без изменения ID, текста и чек-листа.
- Запись не дублируется в базе из-за того, что открыта через несколько представлений.

## Проверки

- Компонентные тесты переключения представлений после добавления/удаления расписания и открытия drawer из каждого представления.
- Тесты для даты без времени, времени/даты и пустого расписания.
- Из-за изменения типов и store выполнить предписанный `AGENTS.md` полный Vitest и build.

## Зависимости

- `TASK-51` — remote-backed store.
