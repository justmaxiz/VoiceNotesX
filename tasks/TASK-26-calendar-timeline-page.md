# TASK-26: Страница «Календарь» с временной шкалой

- **ID:** `TASK-26`
- **Блок:** 6. Дополнительные Страницы Приложения
- **Статус:** Ожидает выполнения
- **Приоритет:** Средний (P2)
- **Зависимости:** `TASK-04`, `TASK-06`

---

## 1. Цель задачи
Создать экран «Календарь» для наглядного планирования задач по дням недели и месяцам с временной шкалой и возможностью быстрой привязки дедлайнов.

---

## 2. Техническое решение

### 2.1. Компонент `CalendarPage.tsx` (`src/components/calendar/CalendarPage.tsx`)
- Переключение видов: «Месяц» / «Неделя» / «День (Timeline)».
- Сетка месяца:
  - Индикация дней с задачами (цветные точки по тегам категорий).
  - Подсветка текущего дня.
- Почасовая шкала (Timeline дня):
  - Отрезки времени с 08:00 до 22:00.
  - Размещение карточек задач с установленным временем дедлайна.
  - Клик по свободному слоту времени открывает быстрое создание задачи на это время.

---

## 3. Критерии приемки (Definition of Done)
1. Календарь корректно отображает задачи с привязкой к датам `dueDate`.
2. Поддерживается навигация между месяцами (Предыдущий / Следующий).
3. Клик по дню фильтрует задачи на этот день.
