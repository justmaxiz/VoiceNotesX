# TASK-38: Календарь: реальные даты дедлайнов, бэклог без даты и почасовая сетка (Calendar Real Due Dates & Backlog)

- **ID:** `TASK-38`
- **Блок:** 8. Улучшения интерфейса, логики и UX
- **Статус:** Выполнено
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-26`, `TASK-37`

---

## 1. Бизнес-цель и контекст
Пользователь столкнулся с критическим багом: при создании задачи в календаре она дублировалась на случайные дни месяца (1, 5, 9, 13, 17, 21, 25, 29 числа). Расследование показало наличие временного хардкода `dayNum % 4 === 1 ? tasksWithDue.slice(0, 1) : []`. 
Цель задачи — полностью устранить этот баг, реализовать строгую и корректную привязку задач к реальным календарным датам (`task.dueDate`), добавить боковую панель задач без даты (бэклог), быстрый ввод кликом по дню календаря, drag-and-drop перенос задач между днями и полноценную почасовую сетку в недельном виде.

---

## 2. Пользовательские сценарии (User Stories)
1. *Как пользователь*, когда я создаю задачу на 18 октября, я хочу видеть ее строго в ячейке 18 октября и ни в каких других ячейках месяца.
2. *Как пользователь*, я хочу видеть боковую панель «Задачи без даты» и иметь возможность перетащить задачу мышью в нужный день календаря.
3. *Как пользователь*, я хочу кликнуть на пустую область любого дня и мгновенно создать задачу именно на эту дату.
4. *Как пользователь*, если в один день назначено много задач (более 3), я хочу видеть компактную кнопку «+ еще 3», клик по которой открывает аккуратный поповер со всеми делами дня.
5. *Как пользователь*, в недельном виде я хочу видеть реальную почасовую шкалу (08:00–22:00) с плашками задач, спозиционированными по времени.

---

## 3. Функциональные и визуальные требования

1. **Исправление распределения задач по дням (`CalendarPage.tsx`):**
   - Полностью удалить искусственный расчет `dayNum % 4 === 1`.
   - Для каждого дня месяца формировать точный ключ даты в формате `YYYY-MM-DD` (с учетом текущего выбранного года и месяца, по умолчанию текущий месяц).
   - Фильтровать задачи: `dayTasks = items.filter(task => task.dueDate && task.dueDate.startsWith(dayDateKey))`.
   - Задача отображается строго один раз — в ячейке своей даты.

2. **Боковая панель бэклога «Задачи без даты»:**
   - Сворачиваемая правая колонка в календаре: список всех активных задач, у которых `dueDate === null` или не задан.
   - Поддержка Drag-and-Drop: перетаскивание задачи из бэклога на ячейку дня календаря немедленно выставляет ей `dueDate` выбранного дня и сохраняет в IndexedDB.

3. **Клик по ячейке дня для создания задачи:**
   - Клик по пустой зоне ячейки дня открывает быстрое создание задачи с уже заполненной целевой датой.

4. **Лимит задач в ячейке месяца:**
   - В ячейке дня отображается до 3 плашек задач.
   - Если задач больше 3: кнопка `+ еще N` (например, «+ еще 2»).
   - Клик по кнопке открывает стилизованный Popover с полным списком задач дня и быстрым чекбоксом выполнения.

5. **Почасовой недельный вид (Week View):**
   - 7 колонок (Пн–Вс).
   - Вертикальная шкала времени с 08:00 до 22:00 с шагом 1 час.
   - Плашки задач позиционируются по вертикали в соответствии со своим `dueTime` (например, 14:30) и высотой по `estimatedMinutes`.
   - Задачи «Весь день» отображаются в верхней закрепленной полосе над временной шкалой.
