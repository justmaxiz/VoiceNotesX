# TASK-28: Страница «Настройки и Профиль» (BYOK API-ключ)

- **ID:** `TASK-28`
- **Блок:** 6. Дополнительные Страницы Приложения
- **Статус:** Ожидает выполнения
- **Приоритет:** Высокий (P1)
- **Зависимости:** `TASK-04`, `TASK-14`

---

## 1. Цель задачи
Создать экран настроек приложения с возможностью ввода и проверки собственного API-ключа Google AI Studio (BYOK), выбора языка распознавания речи, экспорта/импорта базы и очистки данных.

---

## 2. Техническое решение

### 2.1. Компонент `SettingsPage.tsx` (`src/components/settings/SettingsPage.tsx`)
- Секция «Искусственный интеллект (Google AI Studio)»:
  - Поле ввода Gemini API Key с маскированием (`••••••••`) и кнопкой показа/скрытия.
  - Кнопка «Проверить ключ» (тестовый пинг модели).
  - Ссылка на бесплатное получение ключа в Google AI Studio.
- Секция «Голос и распознавание»:
  - Выбор языка: Русский (`ru-RU`), Английский (`en-US`), Автоопределение.
- Секция «Резервное копирование и данные»:
  - Кнопка **«Экспорт всех данных в JSON»** (сохранение полной локальной копии).
  - Кнопка **«Импорт базы данных»** (восстановление из JSON файла).
  - Кнопка **«Очистить все данные»** (с подтверждением модальным окном).

---

## 3. Критерии приемки (Definition of Done)
1. Введенный ключ Gemini сохраняется и используется во всех запросах.
2. Экспорт базы генерирует валидный JSON файл со всеми задачами и заметками.
3. Очистка базы возвращает приложение к исходному состоянию.
